PulseForm

See what you hear.

Phase 1 plan for PulseForm V1: one full-screen listening experience on desktop, iPhone and TV. A liquid-chrome sculpture fills the top, the real signal scrolls below, and controls stay out of the way.

Screen inventory

One main screen per device. Everything else is a sheet or overlay on top of the artwork.

Desktop

  • Player: sculpture, waveform or spectrum, dock
  • Source sheet: microphone, song file, Windows companion
  • Worlds sheet with Surprise Me and saved worlds
  • Connect display: QR code and 6-digit code
  • Settings: motion, flashes, quality, diagnostics
  • Export sheet for song files (9:16, 16:9, 1:1)

iPhone

  • Player with portrait and landscape layouts
  • Pair: scan QR or type code
  • Remote: world, intensity, listen, seek for files
  • Source: microphone or a song file
  • Receive-only mode for headphone listening

TV

  • Display: artwork only, no chrome
  • Pairing card shown until a controller joins
  • Reconnecting state that keeps the visual running

Audio sources

PulseForm reacts to audio it is allowed to hear. It never reads another app's stream directly, and the app says so in plain words.

ModeWhat it hearsLimits shown to the user
MicrophoneMusic playing out loud, through the device mic, after the user taps ListenRoom noise and speaker quality affect results. Stops when the user stops or revokes permission.
Song fileA file the user owns, decoded on the device, with full-track analysisPlays inside PulseForm. Enables seeking, full waveform and MP4 export.
Windows companionSystem output through WASAPI loopback, sent as analysis numbers onlyWindows only. Apps that protect their audio stay silent. Needs a one-time install.
Paired desktopThe phone or TV receives analysis from the desktopFor headphone listening. No audio travels between devices.

There is no Spotify, Apple Music or other streaming-service integration. Those services don't permit reading their audio, so PulseForm doesn't attempt it.

How the sound drives the sculpture

All three bands act at once, each smoothed with its own attack and release so motion reads as weight rather than jitter.

LOW · 20–150 Hz
  • Expansion and contraction
  • Deep pulses on kicks
  • Large surface waves
MID · 150 Hz–2 kHz
  • Organic folds
  • Slow shape transitions
  • Inner colour drift
HIGH · 2–16 kHz
  • Rim shimmer and highlights
  • Fine particle sparkle
  • Small, capped flashes

Known limits

  • The package registry is blocked in the build environment, so Three.js can't be installed yet. Liquid Form is written as a WebGL2 shader that drops straight into Three.js once access is allowed.
  • iOS lets web apps use the microphone but not other apps' audio. Headphone listening on iPhone works only through a paired desktop.
  • Cross-network pairing needs a small signalling server. A local one ships with the app. Hosting it publicly waits for your approval.
  • Beat and section labels are estimates. The interface marks them as estimates.
